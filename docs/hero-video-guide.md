# The hero video

The hero is a 6-second loop built from the real tanker photo (`IMG_9337`, truck #104): the truck
as photographed, its wheels turning, on a highway that streams past in correct perspective.
It is composited from the photo, not generated by AI, so the truck, logo and USDOT number are
exactly what is on the real truck.

## How it is made (tools/hero-video)

1. **Cutout** (`cutout.py`): an AI model separates the truck from the background. It cannot see the
   mirror-polished tank (it reflects the sky), so the trailer's lower outline is hand-traced in
   `masks.py`.
2. **Camera** (`geometry.py`, `calibrate.py`): the photo's camera is recovered from the tyres
   (horizon, height about 1.65 m, heading). Checks: same-side tyres line up to 3 cm, the tractor's
   wheelbase comes out at 5.5 m, tandem spacing at 1.31 m.
3. **Wheels** (`wheels.py`): the real rims and hubs are rotated inside their measured ellipses and
   motion-blurred. `debug_wheels.py` draws the ellipses so they can be checked by eye.
4. **Mountains** (`backdrop.py`): the sky-blue pixels (and the water tower, which is forced out) are
   swapped for a real mountain photo (Caleb Jack on Unsplash, free to use; path in `common.py`). Only
   sky is replaced, so the building, trees and fence stay in front of the mountains. The mirror-polished
   tank would fool a colour key, so its upper outline is hand-traced in `TANK_POLY`, a few pixels outside
   the tank on purpose.
   The mountains are cut out of their own sky by flood-filling the sky from the top edge (it fades
   smoothly, a ridgeline is a real edge), and edge pixels are un-mixed so peaks have no pale rim. Then
   they sit on the truck photo's own sky. To use another photo, change `MOUNTAIN_PHOTO`; slide the range
   up/down or zoom it with `MOUNTAIN_ORIGIN` / `MOUNTAIN_ZOOM`. It works best with a clear sky, shot
   from ground level.
5. **Road** (`ground.py`): real asphalt grain from a clean patch of the photo is straightened,
   tiled and scrolled along the road in true perspective with lane paint. The photo's own light and
   the truck's shadow stay put underneath, so the road stays glued to the truck.
6. **Render** (`render.py`): composites each frame, adds a touch of car vibration, writes the MP4.
   Everything is sized to loop seamlessly.

Re-render (about 7 minutes). Run from `tools/hero-video`:

```
uv run --python 3.12 --with "rembg[cpu]" --with pillow python cutout.py        # once
uv run --python 3.12 --with numpy --with opencv-python-headless --with pillow --with imageio-ffmpeg python render.py --crf 24
uv run --python 3.12 --with numpy --with opencv-python-headless --with pillow --with imageio-ffmpeg python render.py --still 0 20   # preview single frames
```

Paths to the photo and the work folder are set at the top of `common.py`.

## Things to tweak (all at the top of `render.py` / `ground.py`)

- `SPEED`, `LOOP_SECONDS`: how fast the road goes. Keep the loop a whole number of dash periods.
- `WHEEL_STEP`, `WHEEL_BLUR`: how the wheels look when spinning.
- `LINES` in `ground.py`: lane paint (positions are metres from the camera's lane).

## Known limits (be honest with the owner)

- The mountains, trees, building and fence are still; only the road, wheels and a little vibration move. At a glance it reads as a tracking shot; a real drone clip of the
  actual truck will always look more "real company".
- Only this one camera angle exists. A different angle needs a different photo and a re-trace.

## Using other footage instead

A real clip (or an AI image-to-video clip made from the photo) drops in the same way:

1. Save it as `public/video/hero.mp4` (H.264, 1080p, ideally under about 8 MB, no audio needed).
2. Set `HERO_VIDEO_SRC = "/video/hero.mp4"` in `src/data/company.ts`.
3. Optional: set `HERO_POSTER` to a still from it.

Visitors with "reduce motion" or data-saver on get the poster photo instead, and the video fades in
once it is ready.
